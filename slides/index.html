paperlint

A review pipeline for research manuscripts: citations, references, terminology, consistency, and claims — every layer reporting honestly, including when it did not run.

The design law Deterministic candidates; the model only adjudicates. Zero candidates ⇒ zero model calls. Every model verdict must quote text that exists — ungrounded output is dropped and counted, never salvaged.
ExtractHTML / plain text → text + verifiable offsets
Deterministic layersresolve, compare, abstain — no model, no guessing
Candidate generatorsdecide the only questions the model is ever asked
Model adjudicationone candidate at a time, verbatim-quote gated
Advisory findingsdata for a human — never an accept / reject
Failure is silence plus a recorded reason — a truncated run says partial, never “clean”.
paperlint · the deterministic layers2 / 3

Five layers, no model required

01Glossary near-miss
Token-set matching against a canonical glossary. Abstains on ambiguity; single common words never fire.
"kernel support machine"→nearly matches "Kernel Support Vector Machine (KSVM)" — use the canonical term
02Citation resolution
Every DOI / arXiv id resolved (Crossref → DataCite → doi.org; arXiv → OpenAlex). Timeouts are unverified, never accusations.
doi:10.9999/not-a-real-doi→not registered — all three registries had to agree before saying so
03Retraction check
Reads updated-by from the payload already fetched — zero extra requests. Corrections are not flagged.
doi:10.1016/S0140-6736(97)11096-0→was RETRACTED on 2010-02-06 — the notice's own DOI is named so a reviewer can read it
04Reference & float integrity
Cited-but-not-listed, never-cited, duplicates, missing years — plus figures/tables captioned but never referenced, or referenced but missing. Refuses to run unless the style is really in use.
prose cites [5]; the list ends at [4]→"The text cites [5], but the reference list has no entry [5]"
05Summary consistency
Percentages asserted in the abstract that the body never states. Rounding at the summary's own precision is fine.
summary: "45%" · body: never mentions it→"Summaries should not carry figures the body does not support"

Four adjudicators, measured before shipped

D1Claim vs source
"their survey achieved 95% accuracy" · abstract: "we do not report accuracy figures"→unsupported — both quotes verified verbatim, or the finding dies
D2Contradiction
"91.4% accuracy" … later … "99.2% accuracy"→same metric, conflicting values — the model decides if it is truly one quantity
D3Methodology
"a 12-point improvement" · no baseline anywhere in Methods→gap anchored to that exact quoted claim — absence alone is never reported
D4Overclaiming
"our single trial proves the method eliminates hallucination entirely"→evidence (one trial, five examples) cannot carry that strength of claim
