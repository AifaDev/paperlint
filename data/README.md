# Glossary format

The terminology layer takes a JSON array of terms. `glossary.example.json` is a
small hand-written set of generic AI/ML terms so the check works out of the box —
it is a demonstration, not a standard.

```json
[
  {
    "slug": "kernel-support-vector-machine-ksvm",
    "en": {
      "term": "Kernel Support Vector Machine (KSVM)",
      "slug": "kernel-support-vector-machine-ksvm",
      "definition": "A support vector machine using a kernel function to separate classes in a transformed feature space."
    }
  }
]
```

An **attributed envelope** is also accepted, so a vocabulary's credit travels
inside the file rather than only in a README somebody may not copy:

```json
{
  "source": "ICAIRE AI Glossary",
  "source_url": "https://icaire.org/glossary",
  "attribution": "Vocabulary (c) ICAIRE. Keep this attribution with the data.",
  "terms": [ ... ]
}
```

The server prints the source name on boot and reports it at `/api/status`.

## Which file gets loaded

First hit wins, and the choice is always printed - a glossary quietly falling
back to the 33-term example would make the layer look broken rather than
unconfigured:

1. `PAPERLINT_GLOSSARY` - an explicit path beats everything.
2. `data/glossary.json` - a real curated vocabulary, if one is present.
3. `data/glossary.example.json` - the demo set, so a fresh clone still works.

```bash
PAPERLINT_GLOSSARY=/path/to/your-glossary.json npm run web
```

**A real, curated vocabulary works far better than the example.** The
**ICAIRE AI Glossary** — <https://icaire.org/glossary>, ~1,300 terms in
English, Arabic and French — is the vocabulary this layer uses and the source
of the abstention rules in `src/matcher.ts`. Credit it wherever you use it; see
[`../CREDITS.md`](../CREDITS.md).

To bundle it, drop the file at `data/glossary.json` - it is picked up
automatically, in either accepted shape, with no configuration.

## Why the abstention rules exist

A real curated glossary is messier than it looks, and every rule below was
earned against one. In the ICAIRE AI Glossary as of this writing: **143** entries
are `See "…"` cross-reference stubs, **224** are single common words like
*Security* or *Frame*, and **14** slugs are numeric-suffix duplicates whose two
spellings disagree with each other. A matcher that ignored any one of those
would flood ordinary prose with findings.

## What the layer does with it

- An acronym in parentheses is split into its own accepted form, so
  `Artificial Intelligence (AI)` accepts both `artificial intelligence` and `AI`.
- Entries whose definitions are identical and whose slugs differ only by a
  numeric suffix are folded together — a duplicate is not two concepts.
- A surface form that maps to more than one entry produces **no finding**. This
  is the single most important rule: real glossaries are many-to-many, and
  guessing is how a terminology checker starts inventing mistakes.
- Single-word terms are ignored unless explicitly allowlisted. Words like
  *Security* or *Frame* are ordinary English before they are glossary entries.
- Cross-reference stubs (`See "…"`) are excluded entirely.

## Eval records

`eval/` holds the measurements quoted in the README, each generated by a script
in `scripts/` against a public corpus. Every record states what it does **not**
measure; read those caveats before quoting a headline number.
