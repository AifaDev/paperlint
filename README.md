# paperlint

A deterministic-first review pipeline for research manuscripts. Paste or upload
a draft; every layer reports what it found — and says honestly when it did not
run.

**The design law: deterministic candidates, model only adjudicates.** The
deterministic layers decide what questions are ever asked. The optional LLM
layer rules on those candidates one at a time, must quote text that actually
exists (ungrounded output is dropped and counted), and never scans a document
free-form. Zero candidates means zero model calls. Findings are advisory data —
nothing here accepts or rejects a manuscript.

**[The 3-slide tour of the layers →](slides/index.html)**

## Quickstart

```bash
npm install
npm run web        # builds, then serves http://localhost:4173
```

Paste text, or upload a `.pdf` / `.docx` (extracted text fills the editor so you
can see and trim exactly what will be reviewed). The deterministic layers need
no key and no configuration. To activate the model layers (D1–D4), paste a
[Groq API key](https://console.groq.com/keys) into the key panel — it stays in
your browser's localStorage, is sent only to your local server per run, and is
never stored on disk, logged, or written into history.

## The layers

| Layer | What it checks | Needs |
|---|---|---|
| Glossary near-miss | terms that nearly match a canonical glossary entry ("kernel support machine" → "Kernel Support Vector Machine") | a glossary (example bundled; `PAPERLINT_GLOSSARY=` yours) |
| Citation resolution | every DOI/arXiv id resolves, and to the work the prose describes (Crossref → DataCite → doi.org; arXiv → OpenAlex fallback) | network |
| Retraction check | a cited work that was retracted/withdrawn — read from the same Crossref payload, zero extra requests | network |
| Reference & float integrity | cited-but-not-listed, listed-but-never-cited, duplicates, missing years; figures/tables captioned but never referenced, or referenced but missing — abstains unless the style is really in use | nothing |
| Summary consistency | percentages asserted in the summary that the body never states | nothing |
| D1 claim vs source | does the cited work's abstract (optionally full text via BM25 selection) support the claim attached to it? Four verdicts, three silent | Groq key |
| D2 contradiction | the same metric reported with conflicting values | Groq key |
| D3 methodology | missing baseline/ablation/limitations, each anchored to a quoted dependent claim | Groq key |
| D4 overclaiming | "proves/always/eliminates" claims the surrounding evidence does not carry | Groq key |

Every failure is silence plus a recorded reason, never a fake success: rate
limits mark the run `partial` and list what was dropped; an unresolvable DOI is
`unverified`, never an accusation; a non-English document is skipped with a
stated reason rather than judged by English rules.

## Measured, not asserted

The numbers ship in [`data/eval/`](data/eval), generated by the scripts in
[`scripts/`](scripts) against public corpora ([fetch them](scripts/fetch-benchmarks.mjs)
with `npm run bench:fetch`):

| Check | Result | Record |
|---|---|---|
| Retraction detection | recall 150/150, false positives 0/150 (Crossref gold) | `bench-retraction.json` |
| D1 claim-vs-source | precision 0.944, recall 0.215 on 240 Citation-Integrity cases (149 unique pairs — caveat recorded in the file) | `bench-citation-integrity.json` |
| BM25 evidence selection | Recall@5 0.551 at full-paper scale vs a 0.010 lead-5 baseline | `bench-bm25-gate.json` |
| Refutation gate | measured harmful (killed true positives, lowered precision) and **removed** — the measurement that killed it ships too | `bench-refutation*.json` |
| Text-only ceiling on real published errors | 7 of SPOT's 91 errata-grade errors are reachable by any text-only reviewer | `spot-scope.json` |

Every eval record states what it does NOT measure. Read the caveats before
quoting the headlines.

## Library use

```js
const { runReviewPipeline } = require("paperlint/dist/index.js");

const result = await runReviewPipeline(
  { content: text, contentBrief: summary, rowLocale: "en" },
  {
    glossary,                    // MatcherTerm[] — [] disables the layer
    citationStore,               // { get, set } — cache DOI resolutions
    resolveOptions: { mailto: "you@example.org" },   // Crossref polite pool
    modelEnabled: true,          // off by default
    modelOptions: { apiKey: process.env.GROQ_API_KEY },
  },
);
```

Everything that touches the world is injected, which is why the whole test
suite runs offline.

## Privacy

- The web UI binds `127.0.0.1` only.
- Run history (including full manuscript text, never API keys) is stored
  unencrypted in `data/history/` on your machine, gitignored, and deletable
  from the UI or with `rm -r data/history`.
- Outbound traffic is exactly: DOI/arXiv/OpenAlex lookups (identifier-only,
  hardcoded hosts — author-supplied URLs are never fetched) and, with a key,
  Groq API calls carrying the text being reviewed.
